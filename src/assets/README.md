# Imported visual assets

Images/SVGs imported by application source belong here. It currently holds no
images: the unused Vite template images were deleted (D-028), and the interface
draws its icons inline in `src/components/icons.tsx`.
Publicly served model/runtime files belong under `public/`; see the
[public-file rules](../../AGENTS.md#static-files-in-public).

Follow [asset rules](AGENTS.md), keep the GymBro AI identity, and record permission
and provenance for replacements. This directory is not a place for workout footage.
