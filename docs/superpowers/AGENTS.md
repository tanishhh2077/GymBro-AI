# Planning artifacts

Read [documentation guidance](../AGENTS.md) and [root guidance](../../AGENTS.md).

- Store reviewable plans here; a written plan is not implementation authorization.
- Keep plans tied to the current specification, accepted decisions, and actual source.
- Distinguish proposed defaults from requirements the user has approved.
- Do not create application code, install packages, or run future plan commands while performing a planning-only task.
- Preserve historical reviews and unrelated work. Update status when a plan is proposed, revised, or approved.
- Add concise local guidance for new authored planning directories.
